# Lesson 10 - Dialogs, new tabs, uploads and iframes

**Spec file:** `tests/10-dialogs-tabs-uploads-frames.spec.ts`
**Playground:** http://127.0.0.1:4173/playground.html

## 1. Browser dialogs (`alert`, `confirm`, `prompt`)

Playwright **auto-dismisses** dialogs unless you register a handler, which is why
an un-handled `confirm()` behaves as if the user pressed Cancel.

```ts
page.once('dialog', async dialog => {
  expect(dialog.type()).toBe('alert');        // 'alert' | 'confirm' | 'prompt' | 'beforeunload'
  expect(dialog.message()).toBe('Your session will expire in 5 minutes.');
  await dialog.accept();                       // or dialog.dismiss()
});

await page.getByTestId('alert-button').click();
```

- Register the handler **before** the click.
- `page.once` for a single dialog, `page.on` if several will appear.
- `dialog.accept('Priya')` passes text to a `prompt`.
- Accept and dismiss are two different requirements - write two tests.

## 2. New tabs and popups

The new page belongs to the **context**, not the current page:

```ts
const popupPromise = context.waitForEvent('page');   // listen first
await page.getByTestId('new-tab-link').click();

const newTab = await popupPromise;
await newTab.waitForLoadState();
await expect(newTab).toHaveURL(/about\.html/);
await newTab.close();
```

For `window.open` triggered by an element, `page.waitForEvent('popup')` works too.

## 3. File uploads

```ts
// from disk
await page.getByTestId('file-input').setInputFiles('test-data/receipt.txt');

// several files
await input.setInputFiles(['a.png', 'b.png']);

// generated in the test - no fixture file to maintain
await input.setInputFiles({
  name: 'generated.txt',
  mimeType: 'text/plain',
  buffer: Buffer.from('generated by the test run'),
});

// clear the selection
await input.setInputFiles([]);
```

Never try to automate the OS file picker. If the app hides the input behind a
custom button, use the file chooser event:

```ts
const chooserPromise = page.waitForEvent('filechooser');
await page.getByRole('button', { name: 'Attach' }).click();
const chooser = await chooserPromise;
await chooser.setFiles('test-data/receipt.txt');
```

### Downloads (same idea, other direction)

```ts
const downloadPromise = page.waitForEvent('download');
await page.getByRole('button', { name: 'Export CSV' }).click();
const download = await downloadPromise;
expect(download.suggestedFilename()).toBe('orders.csv');
await download.saveAs('/tmp/orders.csv');
```

## 4. Iframes

Locators on `page` cannot see inside a frame. Use `frameLocator`:

```ts
const frame = page.frameLocator('[data-testid="support-frame"]');
await frame.getByRole('button', { name: 'Chat with support' }).click();
await expect(frame.getByTestId('frame-status')).toHaveText('An agent will join shortly');
```

Everything after `frameLocator()` behaves like a normal locator, including
chaining, filtering and auto-waiting. Nested frames: chain another
`frameLocator()`.

## 5. Screenshots on demand

```ts
await page.screenshot({ path: 'shot.png', fullPage: true });
await locator.screenshot({ path: 'element.png' });

// better: attach to the report instead of writing loose files
await testInfo.attach('playground', {
  body: await page.screenshot({ fullPage: true }),
  contentType: 'image/png',
});
```
